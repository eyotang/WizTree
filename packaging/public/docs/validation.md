# 验证范围

- Windows：77 项工作区测试、格式检查、严格 Clippy 与 Release 构建通过；本机原生交互检查通过。
- Linux：Ubuntu CI 的原生扫描、查询与存储测试通过；Xvfb 下运行真实 GPUI 界面，键盘与扫描生命周期检查通过。实际安装包另在 WSLg 启动并完成扫描。
- macOS：Intel 与 Apple Silicon 原生测试及安装包检查通过；Apple Silicon CI 运行真实 AppKit/GPUI 界面，交互检查通过。
- 桌面检查覆盖真实 GPUI 键盘路由、按住 Space、标记去重、浏览历史与滚动恢复、空间图深度、清理前复核、取消及重开确认框、带确认框关闭主窗口、新扫描清空与过期回复丢弃。
- 安装包检查覆盖 Windows EXE 图标资源、Ubuntu DEB 的安装目录/依赖/图标与隔离容器内安装、重装、卸载，以及 macOS 只读 DMG 的 .app、架构、签名与 Applications 入口。同次原生构建的开发 CLI 核对 2055 个文件、中文路径、CSV、单/多线程一致性、缺失目录错误与符号链接跳过；CLI 不在用户安装包中。

测试通过不代表覆盖全部用户环境。原生文件选择器的实际鼠标点击、所有 DPI/字体/显卡组合、系统回收站的全部行为和复杂文件系统权限场景尚未完整自动化覆盖。交互检查不确认真实删除，夹具内容保持不变。

性能按当前实际使用体验验收，扫描器保持现有版本。本次交互修复没有变更扫描算法；CI 的小型夹具检查不作为与其他产品的性能对照。

macOS 当前使用 ad-hoc 签名，未执行 Apple 公证，不声称已通过 Gatekeeper 分发验收。公开安装包须通过内容与开发路径泄漏检查；本文不包含开发机器信息或原始扫描数据。
