# 验证范围

- Windows：77项工作区单元测试、格式检查、严格 Clippy 及 Release 构建通过，桌面运行已查看。
- Linux：WSL 下34项核心测试通过，包含稀疏文件、硬链接、非 UTF-8 文件名、符号链接循环、FIFO、取消与错误处理。
- macOS：Intel、Apple Silicon 的核心及测试目标交叉编译、严格 Clippy 通过；批量属性解码有跨主机边界测试。
- 应用内部集成检查覆盖文件夹弹窗生命周期、键盘焦点、浏览历史、标记去重、新扫描清空与过期返回丢弃。

未完成：macOS/Linux 桌面实机、Mac 文件系统及权限场景、完整回收站系统行为、不同 DPI 与全操作交互、受控冷缓存及其他产品的同条件性能对照。

公开发布的程序须通过包内容和路径泄漏检查。此文档不包含开发机器信息、原始测试数据或内部扫描结果。

当前本地生成的产物为 Windows ZIP 与公开源码 ZIP。macOS DMG 和 Linux 安装包仍需在各自原生构建机生成并验收，工作流存在不等于产物已经生成。
