# 界面设计约定

参考 [ftop](https://github.com/Nongfsq/ftop) 的信息层级、统一图标和轻量控制，结合 apple-design 的即时反馈、空间一致性和克制原则。界面由 Rust + GPUI Kit 原生绘制，未复制 ftop 的 Swift 实现或素材。

- 顶部仅保留位置、扫描和常用操作；摘要使用同尺寸的圆形图标、等宽分组以及分离的数值/单位。
- 目录表、空间图和详情使用统一表面、圆角和留白。高级筛选按需展开，收起后保留条件数量提示。
- 互斥视图使用分段控件；详情页签使用下划线；独立开关使用图标和淡色底；文件复核使用标准复选框，分别表达其语义。
- 保留组件库的按下反馈、键盘导航和焦点指示。页签沿当前位置重定向弹簧，使用无回弹阻尼；遵循系统减少动态效果设置，也可在空间图设置中关闭界面动效。
- 浅色与深色共用布局和语义色。扫描时清空上次结果的行为保持一致；没有新增数据库或扫描中的装饰动画。

## 本地视觉验收

可用 `cargo run -p wiztree-desktop --features appearance-smoke -- <示例目录> --smoke-appearance` 生成实际原生渲染截图。设置 `WIZTREE_SMOKE_OUTPUT` 为已有输出目录，并用 `WIZTREE_STATE_DIR` 指向独立测试设置目录，避免影响日常偏好。该入口仅在显式启用验收功能时编译。

Windows 已检查浅/深色、展开筛选、文件类型与复核页签，以及 1060 像素宽窗口；macOS/Linux 的原生显示仍需对应系统验收。
